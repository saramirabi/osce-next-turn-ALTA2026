# Shared slide files

Theme templates (`themes/`), slide chrome (`chrome.css`, `chrome.html`), title-card
styles (`section-divider.css`) and the bundled Plus Jakarta Sans font (SIL OFL,
`fonts/plus-jakarta-sans/OFL.txt`). Adapted from the ALTA 2026 Tutorial 2 slides
(tdszyman/alta2026-evaluating-ai-agents). `themes/green.scss` is the default.

`alta-2026-logo.png` is the ALTA 2026 logo from the conference site
(https://alta2026.alta.asn.au/), shown on the title and closing slides.
